# Game types stored in the DS byte and bitfield order under EIDOS_SSO.
#
# tools/dsaddr.py --sso wraps each listed struct or union's definition (by
# tag, or by typedef name for an anonymous one) in
# #pragma scalar_storage_order little-endian, in every game source and in
# every header the overlay build copies.  Every other game type keeps the
# host order, which is what the decompiled code's raw-pointer views of its
# own structs assume (NNSi_FndGetMBlockRegion reads a block's size as
# blk[1], written through the struct): storing a punned type in the DS
# order breaks it.
#
# List a type only when the game reads a hardware or firmware word through
# its bitfields or a union with a raw view, and the port writes the other
# side in the DS order (types.h, bw_gs_rd16..bw_gs_wr32); or when it is the
# view of bytes that stay in the DS order on every host, as a compressed
# stream's header word does (no extractor turns a compressed member, and
# MI_UncompressLZ8 reads that word as the DS's).  One name per line, then
# why.
PXIFifoMessage       PXI_SendWordByFifo: the tag:5/err:1/data:26 bitfields over the FIFO word
RTCRawDate           the ARM7 stand-in's RTC block at 0x02FFFDE8 (sdk/arm7/rtc.c)
RTCRawTime           the RTC block at 0x02FFFDEC
RTCRawStatus2        the RTC block at 0x02FFFDEA
RTCRawAlarm          the RTC block at 0x02FFFDEC
OSiNvramOwner        the firmware user settings at 0x02FFFC80 (sdk/firmware.c)
NvTpPoints           the touch-panel calibration in those settings
OSiNvramSystemWork   another view of those settings
OSiOwnerRtc          the RTC offset in those settings
LzHeader             ARC_UTIL_LoadMember*'s view of an LZ member's header word (type | size << 8)
CompHeader           CLACT_LoadArchiveData's view of the same word
BgTileSource         BG_SYS_PushTileSource's view of a compressed tile source's header word
GXOamAttr            an OAM entry: attr0..attr3, the attr01/attr23 words and the bit-fields all view it; OAM holds the DS's order (sdk/dsmem.h, bw_host_in_oam)
OamAttr              clact.c's and nns_g2d_renderer.c's own copies of that view (attr01 and its bit-fields)
OamEntry             double3Ddisp.c's view of an entry (two words, or attr01 and attr2, attr3)
GXOamAffine          the affine parameters, the fourth halfword of four entries, loaded into OAM
SPLFileHeader        an SPL particle archive (SPA): its file header (the files stay in the DS's order: no extractor turns them)
VramHeapHeader       SPL_EMITTER_FreeNodeToHeap's view of that header (record and texture counts)
SPLResourceHeader    an SPA emitter record's 0x58-byte header, bit-fields and words
SPLResourceFlags     the record's flags word
VramNodeFlags        SPL_EMITTER_FreeNodeToHeap's view of that word (which blocks follow the record)
VramResourceHeader   SPL_EMITTER_SetupResource's view of the record (words, shifts on the bit-field words, bytes)
VramAllocClass       SPL_EMITTER_FreeTexNode's view of the record (flags, lifetimes)
RigDescriptor        the renderers' view of the record
SubFlags             its flags word, two views
SubZeroFlags         one of them
SubDescBits          the other
Sub28Flags           the record's misc word, as the renderers read it
SPLScaleAnim         the scale animation block after a record
SPLCurveInOut        its curve, and the alpha animation's
SPLColorAnim         the colour animation block
SPLCurveInPeakOut    its curve
SPLAlphaAnim         the alpha animation block
SPLTexAnim           the texture animation block
SPLChildResource     the child particles' block
SPLChildResourceFlags its flags halfword
ParticleDesc         SPLEmitter_EmitChildren's view of the child block
ParticleDescFlags    its flags halfword
RigDescriptorHw      the renderers' view of the child block
SubHwFlags           its flags halfword
SubSelFlags          its second misc word
VramSub14            SPL_EMITTER_SetupResource's view of the child block (its second misc word)
RandomVecRange       the gravity and random behaviour blocks (s16 x, y, z and a fourth)
ScaledVecSource      the magnet behaviour block
AxisAngleKey         the spin behaviour block
InterpTargetParam    the collision plane behaviour block (a word, a halfword, bit-fields)
LerpSource           the convergence behaviour block
SPLTextureResource   an SPA texture's header; texels and palettes are bytes the port's texture decoder reads as the DS's
spl_emitter.c:VramResource  SPL_EMITTER_FreeNodeToHeap's view of that header (nns_g2d_oam_manager.c has its own VramResource, host order)
SPLTextureParam      the texture's parameter word, there and in the SPLTexture it is copied into raw (a word load and store keep the DS's bytes)
particle.c:BlkInner   PARTICLE_EMITTER_SetEmitPos's view of the SPA record (emitterBasePos)
mcss.c:McssSysFlags  the MCSS system's flag word: MCSS_SetOrthoMode sets bit 0 with masks, the draw reads it as orthoMode (a runtime word, stored in the DS's order so the masks and the bit-fields agree)
mcss.c:McssFlags     an MCSS object's flag word: masks set loaded (0x2000), alpha, the shadow alpha and more; MCSS_Draw reads the bit-fields
mcss.c:McssRequestFlags  its request word, the same two views
printsys.c:TextPrinterFlags  a text stream's flag byte: PRINTSYS_PrintStreamReleasePause sets advance with raw |= 4, the task reads the bit-fields (a big-endian host's byte order of bit-fields put advance at bit 5, and the intro's text never moved on)
printsys.c:PrintQueueState   the print queue's state byte, the same two views
printsys.c:PrintPos          a print job's pen word: masks and shifts on raw (the colour mode at bits 20..23) and the bit-fields
